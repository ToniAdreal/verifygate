**Most likely cause**

The current implementation probably:

1. Does **not convert the input to lower‑case**.  
2. Replaces each non‑alphanumeric character (including punctuation and spaces) with a hyphen **individually**, so consecutive spaces/punctuation become multiple hyphens.  
3. Does **not strip leading/trailing hyphens** after the replacement.

In short, the function lacks the typical slug‑ification steps: lower‑casing, collapsing any run of non‑alphanumerics into a single hyphen, and trimming edge hyphens.

**Smallest next fix to try**

Replace the body of `slugify` (or edit the existing logic) with a concise, correct version, e.g.:

```python
import re

def slugify(text: str) -> str:
    # 1. lower‑case
    text = text.lower()
    # 2. replace any sequence of non‑alphanumeric chars with a single hyphen
    text = re.sub(r'[^0-9a-z]+', '-', text)
    # 3. strip hyphens from the start and end
    return text.strip('-')
```

- It adds only three lines (lower‑case, regex substitution, strip).
